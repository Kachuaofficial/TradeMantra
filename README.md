# TradeMantra

TradeMantra is a modern stock trading web application designed to deliver a clean, intuitive experience for traders and investors. The project is built with a React frontend and includes a backend placeholder for future trading logic, data fetching, and execution services.

## 🚀 Project Overview

- **Frontend:** React application using `create-react-app`
- **Backend:** Placeholder `backend/test.js` file for future server-side trading and market integration
- **Goal:** Make stock research, portfolio viewing, and order execution easy, responsive, and beautiful

## ✨ Key Features

- Responsive stock trading dashboard
- Clean user interface with market insights
- Easy local setup for frontend development
- Ready for backend expansion with API, authentication, and trading services

## 📁 Repository Structure

## 🧩 Frontend Setup

1. Open a terminal in the `frontend` folder
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
4. Open the app in your browser at `http://localhost:3000`
